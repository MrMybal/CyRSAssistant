## Choose the interface language {#overview}

Open Options > Language and choose English or Français. The change applies immediately and is saved in ReShade.ini for this game. Existing chat messages retain their original language. A request already in progress finishes in the language in which it started.

## Read the manual in your language {#reader}

Help opens the manual in the interface language. In the reader, use the language selector in the header to switch between the complete English and French editions. The current page and section remain selected.

Type in the search field at the top, or press Ctrl+K. Use the nested sidebar to expand a topic and choose a subpage. Hover or focus a shortened label to read its full title and description. F1 returns to Start here in the reader.

## Reading and personal notes {#reading}

Use browser zoom to change text size. Reading positions, open navigation branches and code tabs are retained during the session. My space contains bookmarks and notes; persistence depends on the browser’s local storage policy. Image enlargement stays inside the documentation window and Escape reduces it.

## Available translations {#adding-language}

English is the original and default language. French includes the same pages, sections and media explanations. Other languages are offered only when a complete edition is available. Shader filenames, API identifiers, compiler messages and existing conversations can keep their original spelling or language.
