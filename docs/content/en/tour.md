## Overview {#overview}

| Area | Purpose |
| --- | --- |
| Header | Provider status and permission mode. |
| Chat | Conversation, progress, cancellation and approvals. |
| Options | Language and permission mode. |
| Connection | Provider, model, endpoint, session-only key and connection. |
| Effects | Scan/reload, techniques, values, undo, presets and generated FX. |
| Shaders | Native hashes, inspection and restoration. |
| Help | Offline manual, search, illustrations and diagrams. |

Provider readiness is not a measure of effect quality. Check the effect status separately. Collapsing Techniques or Parameters hides rows without disabling effects.

Use Open documentation in Help, or a contextual Help button beside the tools. CyDoc opens the exact page in the default browser; no WebView, local server or reader installation is required.

Use browser zoom to adjust reading size. CyDoc preserves reading positions, code tabs and navigation during the reader session. Ctrl+K opens search; F1 returns to Start here. Image enlargement stays inside the reader and Escape reduces it.
