## Vue d’ensemble {#overview}

| Terme | Sens |
| --- | --- |
| FX / FXH | Source d’effet ReShade / fichier inclus. |
| Technique | Technique de rendu d’un FX ; un fichier peut en exposer plusieurs. |
| Uniform / paramètre | Valeur d’un effet, éventuellement en lecture seule ou pilotée par ReShade. |
| Preset | Fichier de réglages ReShade courant, avec activations et valeurs. |
| Shader natif du jeu | Bytecode du rendu du jeu, distinct d’un FX ReShade. |
| Empreinte / hash | Identité de contenu, pas un nom de fonction visuelle. |
| DXBC / DXIL | Formats de bytecode traités par les backends compatibles. |
| PSO / root signature | État de pipeline DX12 / contrat de ressources. |
| Compagnon | Exécutable d’arrière-plan reliant l’add-on au fournisseur. |
| MCP | Interface stdio d’outils pour clients externes. |
| Génération / révision | Jetons de version refusant une modification obsolète. |
