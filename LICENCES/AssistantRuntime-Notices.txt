CyRSAssistant assistant runtime notices

The companion is a private, self-contained Windows x64 executable.
It contains CyRSAssistant code (GPL-3.0-only), CPython 3.11.5, the
PyInstaller 6.20.0 bootloader and its required Python runtime hooks.
